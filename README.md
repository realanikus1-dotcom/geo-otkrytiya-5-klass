# Великие географические открытия — интерактивный объяснятор для 5 класса

По учебнику: А. И. Алексеев и др. «География. 5 класс», раздел «История географических открытий». Цель — чтобы ученик уверенно решал задания 4, 5 и 6 ВПР по географии («История географических открытий», каталог «Решу ВПР»).

## Файлы

- `index.html` — стартовая страница.
- `geo-otkrytiya-5-klass.html` — сам объяснятор: 10 интерактивных вопросов с картой, «Сравни маршруты», тренажёр ВПР и шпаргалка.
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий (или папку в существующем) и загрузите все файлы из этой папки, включая `.nojekyll`.
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

Ссылка на конкретный раздел: `geo-otkrytiya-5-klass.html#12` (номер раздела после `#`).

## Технически

- Один HTML-файл без сборки и без библиотек. Шрифты (Playfair Display, Golos Text) грузятся с Google Fonts; без интернета страница работает с системными шрифтами.
- Контуры материков — Natural Earth (общественное достояние), упрощённые и встроенные в файл.
- Страница ничего не сохраняет и никуда не отправляет.
- Работает на компьютере, проекторе и телефоне.
